Item title:
DISTRO - Smart Group Campaign Manager

Short description (≤132 chars):
Schedule and broadcast your marketing posts across joined Facebook groups from one simple dashboard.

Detailed description:
DISTRO is a local-first marketing workflow for community managers and small businesses.

Draft once, choose your Facebook groups, and schedule posts from your browser — on desktop or via the mobile dashboard. Publishing runs through your own Chrome session on your computer. DISTRO never asks for your Facebook password.

KEY FEATURES:
• Sync joined Facebook groups into your DISTRO dashboard
• Create campaigns with text, images, and optional WhatsApp CTA
• Schedule immediate, one-time, or recurring posts
• Run publishing locally via the Chrome extension with safety delays
• Switch Facebook profiles on a shared computer without retyping passwords

HOW TO USE:
1. Install DISTRO and open https://distro-ecru.vercel.app
2. Sign in, then open Facebook and sync your groups
3. Create a campaign, pick groups, and schedule — the extension handles posting

2) PRIVACY PRACTICES — paste into Developer Console
--------------------------------------------------------------------------------
Single Purpose Description:
DISTRO provides a local marketing workflow that helps users manage and automate posting their own content across Facebook groups they manage or have joined.

Permission Justification — cookies:
Required solely to verify if the user has an active authenticated session on Facebook. This enables local group posting without prompting the user to re-enter sensitive account credentials or passwords inside the extension.

Permission Justification — alarms:
Required to schedule and wake the background service worker at user-defined campaign execution times, enabling reliable automated posting intervals without running constant background loops.

Permission Justification — storage:
Used exclusively to store user campaign preferences, group preset IDs, and UI configuration settings locally on the user's device.

Permission Justification — tabs:
Required to open or focus the user's Facebook tabs when syncing joined groups and when executing a user-scheduled campaign post sequence.

Permission Justification — scripting:
Required to inject the DISTRO content helper into Facebook pages so the extension can sync the joined-groups directory and fill the native Facebook post composer with the user's own campaign content.

Permission Justification — notifications:
Optional user-facing alerts when a scheduled campaign that was waiting while the computer was offline begins publishing after catch-up.

Host Permissions Justification (*://*.facebook.com/*):
Required to access the user's joined groups directory at https://www.facebook.com/groups/joins/ to sync group lists, and to interact with the Facebook group post composer to publish user-created marketing posts locally.

Host Permissions Justification (https://distro-ecru.vercel.app/*):
Required to communicate with the user's DISTRO dashboard API to sync group lists, receive queued campaigns (including jobs created from mobile), and report publish status. Localhost entries are for development only.

Data usage checklist:

- Authentication: DISTRO session token only (not Facebook passwords)
